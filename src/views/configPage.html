通知渠道

至少开启一个渠道，提醒才能真正送达。配置完点右侧「测试」确认能收到。
微信推送 未配置
手机微信直接收消息，无需企业微信 · 最适合家人
在 wxpusher.com 用微信扫码登录 → 关注应用 → 「我的」里能看到 UID。
想推给一群人时用主题 ID，个人使用留空即可。
发到微信「服务通知」里，点开即可阅读。
企业微信应用消息 未配置
成员开通「微信插件」后，消息直接进个人微信
企业微信管理后台 →「我的企业」→ 底部「企业 ID」。
「应用管理」→ 自建应用 → 详情页顶部的 AgentId（纯数字）。
填企业微信里的「账号」（不是手机号）。@all 表示应用可见范围内所有人。
需要在企业微信后台把「可信 IP」或「企业可信域名」放通，否则会提示 60020。
企业微信群机器人 未配置
推到群里，适合家庭群、团队群共享提醒
群聊右上角 →「群机器人」→ 添加后复制 Webhook。
QQ 提醒 未配置
通过 OneBot 协议发到 QQ 私聊或群
NapCat / Lagrange / go-cqhttp 的 HTTP 服务地址（包含端口，不带路径）。必须是公网可访问地址。
QQ 渠道需要一个 24 小时在线的 OneBot 服务；没有的话可以只用微信渠道。
Telegram 未配置
通过 Bot 发到 Telegram 私聊、群或频道 · 免费无限量
在 Telegram 里搜 @userinfobot 发一句话，它会回你的 ID；群 ID 是负数，把机器人拉进群后从 @getidsbot 获取。
发到某个话题时填数字编号；普通私聊或群留空即可。
提示：先在 Telegram 里给机器人发一句 /start，否则机器人无法主动私聊你。
邮件 未配置
发到邮箱，可抄送多人 · 支持 Resend / Brevo 两家
两家都只要一个 API Key，不用自己买域名。
Resend 可先用 onboarding@resend.dev 发给你注册时那个邮箱；Brevo 需在后台「发件人」里先验证该邮箱。
可以用 QQ 邮箱、163、Gmail 等任意邮箱。
邮件里是排版好的 HTML，手机上直接可读。
密钥类字段保存后会隐藏。再次保存时留空表示不修改，要彻底删除请点「清除」后再保存。

所有日期、农历换算、发送时段都以这个时区为准。国内用户请选 Asia/Shanghai。
一个都不选 = 全天任意整点都可发送。选中的小时之外，系统会跳过不推送。

修改后台登录账号；密码留空表示不修改
建议 12 位以上，包含字母、数字与符号。
