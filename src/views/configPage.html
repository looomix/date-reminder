通知渠道

至少开启一个渠道，提醒才能真正送达。配置完点右侧「测试」确认能收到。
微信推送 未配置
手机微信直接收消息 · 扫码拿 token 长期有效，与下方 QQ 共用一个 token
www.pushplus.plus 用微信扫码登录 → 「一对一推送」页复制 token。token 长期有效，不会过期。
PushPlus「一对多推送」里创建群组后得到的编码；只发给自己留空即可。
收消息前先关注公众号「pushplus 推送加」，否则发得出去、你收不到。
企业微信群机器人 未配置
推到群里，适合家庭群、团队群共享提醒
群聊右上角 →「群机器人」→ 添加后复制 Webhook。
QQ 机器人 未配置
经 PushPlus 绑定 QQ 官方/自有机器人，私聊或群聊收提醒 · 与上方微信共用 token
和上面「微信推送」填同一个 token（两边填一处即可）。先在 PushPlus「渠道配置 → QQ机器人」里绑定：扫码把机器人加为好友即可；有自己的机器人则填 AppID/AppSecret 绑定。
PushPlus 渠道配置里新增「QQ群」后得到的编码。填了发到群，不填发给自己（机器人私聊）。
提示：QQ 渠道日限 200 次（实名用户）；实名用户消息只显示标题摘要，点击可看全文。
Telegram 未配置
通过 Bot 发到 Telegram 私聊、群或频道 · 免费无限量
在 Telegram 里搜 @userinfobot 发一句话，它会回你的 ID；群 ID 是负数，把机器人拉进群后从 @getidsbot 获取。
发到某个话题时填数字编号；普通私聊或群留空即可。
提示：先在 Telegram 里给机器人发一句 /start，否则机器人无法主动私聊你。
邮件 未配置
发到邮箱，可抄送多人 · 可用自己的 QQ / 163 / Gmail，也可用 Resend / Brevo
直接从 Cloudflare 连邮件服务器发信，不经过第三方，收件人看到的发件人就是你自己。
选一个，下面三项自动填好。
怎么拿授权码：QQ 邮箱 → 设置 → 账号 → 开启 IMAP/SMTP → 生成授权码；163 / 126 → 设置 → POP3/SMTP/IMAP → 开启 → 新增授权码； Gmail → 开两步验证后生成「应用专用密码」。填登录密码一定失败。
Resend 可先用 onboarding@resend.dev 发给你注册时那个邮箱；Brevo 需在后台「发件人」里先验证该邮箱。
收件人随便哪个邮箱都行：QQ、163、126、Gmail、Outlook、公司邮箱都可以。
收到提醒后点「回复」，邮件会发到这个地址（只在用 Resend / Brevo 时有意义）。
邮件里是排版好的 HTML，手机上直接可读。
密钥类字段保存后会隐藏。再次保存时留空表示不修改，要彻底删除请点「清除」后再保存。
